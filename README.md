## 常见问题

**香港为什么比大阪贵这么多？**
主要是线路成本。香港 CN2 GIA 是电信精品网直连，机柜和带宽成本本身就高，全行业在香港做三网直连的 VPS 都不便宜，搬瓦工这个价格在同类里不算离谱，但也确实把大部分个人用户挡在了门外。

**大阪软银和大阪 CN2 GIA 是同一个机房吗？**
不是。软银 JPOS_1 和 CN2 GIA 的 JPOS_6 是两个独立节点，线路、套餐归属、带宽都不同。买 CN2 GIA-E 只能迁软银，买 OSAKA 专属套餐落在 JPOS_6，别在下单前搞混。

**流量用超了怎么办？**
所有套餐的流量按月重置，超出的部分按官网公布的规则另行计费。500GB 对建站和轻量使用一般够用，跑大流量业务就往高档位选，或者直接选 CN2 GIA-E 的大流量版本。

**买完还能换机房吗？**
可以。不同套餐开放的可迁移范围不一样，HK 和 OSAKA 专属套餐能在香港、大阪、东京、新加坡等节点之间切换，CN2 GIA-E 的范围更大，具体以后台迁移页面显示的列表为准。

**两个方向哪个更适合跑对延迟敏感的应用？**
远程桌面、实时连接这类场景，香港的 50ms 平均延迟和三网直连带来的稳定性是硬优势；大阪的价值在带宽和价格，纯拼线路质量它不占上风。
